初回（全カテゴリが 0 点）の伝え方

初回も専用の画面にはせず、同じ画面のままゴーストが並ぶだけにする。保存ボタンも出したまま にする（中身の無い記録ができるだけで、消せばよい）。 残る論点はゴーストがタップできると気づけるかで、次の 3 案を比べる。

＋
＋
1. ゴーストのみ
規則そのまま。何も足さない。破線の枠は「埋められる場所」として広く使われる表現でも あるので、これで足りる可能性はある。
＋
＋
2. ＋ 記号
ゴーストの見た目の一部なので、画面の状態による分岐にならない。あとで 0 点に戻った ときにも効く。細い帯揚げ・帯締めには入らないため、着物と帯にだけ置いている。
＋
＋

薄い部分をタップすると登録できます

3. 案内文
何が起きるかまで言葉で説明できる。ただし全カテゴリ 0 点のときだけという分岐を持ち、 一度登録すると二度と出ないため、あとで 0 点に戻ったときには助けにならない。
